# Taskitator Android — Phase 1 source

Native Android Kotlin / Jetpack Compose application. This ZIP is intended for the `spacexmzez-bit/taskitator-android` GitHub Actions debug APK workflow.

See [PHASE1_STATUS.md](PHASE1_STATUS.md) for implemented features, known gaps, and test status. **Phase 1 is not yet accepted as full website parity.**

The Android app uses the existing Cloudflare Worker; no backend is bundled or deployed from this ZIP. No secrets or private signing keys should be added.
