# Taskitator Android — Phase 2 source

Native Android Kotlin / Jetpack Compose application for the Taskitator Phase 2 integration build.

See [PHASE2_STATUS.md](PHASE2_STATUS.md) for the implemented features, successful CI build, and remaining website-parity gaps. Phase 2 is a working integration milestone, **not yet full website parity**.

The Android app uses the existing Cloudflare Worker. No backend is bundled or deployed from this repository. Do not add secrets, provider API keys, session tokens, or private signing keys to this source.
